NOTA IMPORTANTE PARA DESPLEGAR:
1. Abre Codigo_corregido.gs en Apps Script y cambia el valor de
   API_KEY por una clave propia (no uses la de ejemplo).
2. Copia esa MISMA clave en HRM-System/js/api.js (constante API_KEY).
3. Vuelve a publicar el Web App (Implementar > Nueva implementación)
   para que el backend actualizado quede activo en la URL en uso.
4. No subas la carpeta .git a ningún hosting público.

NUEVO - SEGURIDAD / LOGIN:
5. La primera vez que el backend corre, se crea automáticamente una
   hoja "BD_USUARIOS" con un usuario de ejemplo:
       usuario:    admin
       contraseña: admin123
   CAMBIA esa contraseña de inmediato: inicia sesión con ese usuario
   y usa "Cambiar contraseña" en el menú del usuario (arriba a la
   derecha de la app). No hace falta tocar la hoja a mano para eso.
6. Para dar de alta a MÁS usuarios, agrega filas a mano en la hoja
   "BD_USUARIOS" (columnas: USUARIO, SALT, PASSWORD_HASH, NOMBRE,
   ROL, ACTIVO). Para generar SALT+PASSWORD_HASH de una contraseña
   nueva, corre en el editor de Apps Script una función temporal como:
       function generarHashParaNuevoUsuario() {
         const salt = Utilities.getUuid();
         Logger.log('SALT: ' + salt);
         Logger.log('HASH: ' + hashPassword('la-contraseña-elegida', salt));
       }
   y copia esos dos valores a la hoja. (Se dejó fuera de la interfaz
   a propósito, para no construir una pantalla completa de gestión
   de usuarios en esta versión).
7. Toda acción del backend (incluida la simple lectura de la lista)
   ahora exige haber iniciado sesión — antes "list" estaba abierta.
8. Cada alta/edición/baja de Personal y de Horarios queda registrada
   en la hoja "BD_AUDITORIA" (se autogenera) y es visible desde la
   app en el menú lateral → "Actividad".
9. Desde el modal de Horarios se puede descargar (CSV) o copiar el
   horario de un empleado en particular, o descargar TODOS los
   horarios registrados del sistema con el botón "Exportar Horarios"
   del menú lateral.
